# Research is retained privately

Only this public policy note belongs in this directory. The original research
snapshot was copied outside public Git and configured sync roots, with both
tracked Git bytes and original working-copy bytes verified before candidate
removal. The copy retains the existing local-machine access boundary; it is not
an encrypted or exclusive-user vault. Readers and retention remain decisions.

New source packages reject tracked research payloads, even when Git ignore rules
or export attributes would hide them. Source switching refuses existing research
payloads before changing managed source. Operators must verify private
preservation and migrate that research before retrying an upgrade.

Older commits, clones, caches and previously retained release artifacts can still
contain research. This change does not purge history. Keep older research-bearing
artifacts private and use their exact paired recovery tooling.

The research tools currently default to this directory. Do not run scans or builds
from a public checkout; use a private workspace and private output instead.
Ignored local output is not authorization to publish it or contact anyone.
Research records do not establish business ownership, inbox verification, claim
authority or consent to outreach. Do not import them as verified app accounts.
